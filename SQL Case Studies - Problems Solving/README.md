# SQL Portfolio

A collection of SQL case studies showcasing analytical problem solving, advanced querying techniques, and business-rule implementation using PostgreSQL.

## Overview

To strengthen my SQL skills, I completed a lot of SQL problems From `Codewars` and `HackerRank`, this repo only the most challenging ones I faced and I came with a good approach for solving them.

The projects below focus on translating business requirements into SQL logic rather than simply applying syntax.

---

## Projects

### 1. Contest Streak Analysis
**Concepts:**
- Streak Detection
- Window Functions
- ROW_NUMBER
- Aggregation
- Ranking

**Problem:**
Identify hackers who maintained a submission streak from the beginning of a contest and determine the top submitter for each day.

📁 `contest-streak-analysis/`

---

### 2. Pareto Principle (80/20 Rule)
**Concepts:**
- Customer Segmentation
- Ranking
- Percent Calculations
- Aggregation

**Problem:**
Determine what percentage of rentals were generated by the top 20% of customers.

📁 `pareto-principle-analysis/`

---

### 3. User Registration Trends
**Concepts:**
- Recursive CTEs
- Calendar Tables
- Moving Averages
- Time-Series Analysis

**Problem:**
Generate daily signup counts and an 8-day moving average while including dates with no registrations.

📁 `user-registration-trends/`

---

### 4. Challenge Rankings with Tie Handling
**Concepts:**
- Multi-Stage Aggregation
- Tie Analysis
- Business Rules
- CTEs

**Problem:**
Rank challenge creators while applying special tie-handling rules.

📁 `challenge-ranking-with-ties/`

---

### 5. Student Performance Improvement Analysis
**Concepts:**
- Conditional Aggregation
- Date Analysis
- Trend Detection

**Problem:**
Identify students who demonstrated consistent improvement across three academic terms.

📁 `student-performance-improvement/`
